# Hướng Dẫn Sử Dụng API UpdateFormation

## 1. TỔNG QUAN

**Endpoint:** `PUT /api/match-rooms/{roomId}/formation`

**Mục đích:** Captain của team A hoặc B có thể set formation (sơ đồ chiến thuật) cho team của mình.

**Yêu cầu:**
- User phải đăng nhập (Bearer token)
- User phải là participant của room
- User phải là **Captain** của team mà mình muốn set formation
- Room phải ở trạng thái `Open`

## 3. CẤU TRÚC REQUEST BODY

### Field: `team`
- **Type:** String
- **Required:** ✅
- **Valid values:** `"A"` hoặc `"B"`
- **Ý nghĩa:** Team nào muốn set formation

### Field: `formationName`
- **Type:** String
- **Required:** ✅
- **Valid values:** Tùy theo match format (xem bảng dưới)

### Field: `assignments`
- **Type:** Array of objects
- **Required:** ✅
- **Structure:**
  - `playerId` (UUID): ID của player trong team
  - `slotId` (String): Vị trí slot (format: `{Position}-{Index}`)

## 5. QUY TẮC VALIDATE

### ✅ Validation Rules
1. **Formation phải hợp lệ:** `formationName` phải match với `matchFormat` của room
2. **Slot ID phải đúng:** Mỗi slot trong request phải tồn tại trong formation đó
3. **Player phải trong team:** Tất cả `playerId` phải là member của team đang set
4. **Không duplicate slot:** Mỗi slot chỉ được assign 1 player
5. **Không duplicate player:** Mỗi player chỉ được assign vào 1 slot
6. **Phải là Captain:** User gọi API phải là captain của team

### ❌ Các Lỗi Thường Gặp

| Error Code | Lý do |
|------------|-------|
| `MatchRoom.NotFound` | Room không tồn tại |
| `MatchRoom.NotParticipant` | User không phải thành viên room |
| `MatchRoom.NotCaptain` | User không phải captain của team |
| `MatchRoom.RoomNotActive` | Room không ở trạng thái Open |
| `MatchRoom.InvalidFormation` | Formation không hợp lệ (VD: dùng "4-3-3" cho 5vs5) |
| `MatchRoom.InvalidSlotId` | Slot ID không tồn tại trong formation (VD: "DF-5" trong "4-3-3") |
| `MatchRoom.PlayerNotOnTeam` | Player không thuộc team đang set |
| `MatchRoom.DuplicateSlotAssignment` | Một slot bị assign 2 lần |
| `MatchRoom.DuplicatePlayerAssignment` | Một player bị assign vào 2 slot |

## 7. DATABASE - TABLES ĐƯỢC TẠO/CẬP NHẬT

### 🗃️ Table 1: `match.MatchFormations`

Lưu thông tin formation của mỗi team.

**Khi request thành công:**
- Nếu **chưa có** formation cho team → **INSERT** 1 record mới
- Nếu **đã có** formation cho team → **UPDATE** record đó

**Columns:**
```sql
FormationId        uuid (PK)
RoomId             uuid (FK → MatchRooms.RoomId)
TeamAssignment     varchar(20)  -- "A" hoặc "B"
FormationName      varchar(20)  -- "4-3-3"
MatchFormat        varchar(50)  -- "ElevenVsEleven"
```

**Example Record:**
```
FormationId:      "abc-123-def-456"
RoomId:           "3fa85f64-5717-4562-b3fc-2c963f66afa6"
TeamAssignment:   "A"
FormationName:    "4-3-3"
MatchFormat:      "ElevenVsEleven"
```

**Constraint:** 
- `UNIQUE (RoomId, TeamAssignment)` → Mỗi room chỉ có 1 formation cho mỗi team

---

### 🗃️ Table 2: `match.FormationAssignments`

Lưu chi tiết player nào đang ở slot nào.

**Khi request thành công:**
- **DELETE** toàn bộ assignments cũ của formation
- **INSERT** lại các assignments mới từ request

**Columns:**
```sql
AssignmentId       uuid (PK)
FormationId        uuid (FK → MatchFormations.FormationId)
PlayerId           uuid (FK → Users.UserId)
SlotId             varchar(10)  -- "GK-0", "DF-1", "MF-2", "FW-0"
```

**Example Records** (formation "4-3-3" có 11 records):
```
AssignmentId: "aaa-111" | FormationId: "abc-123" | PlayerId: "user-1" | SlotId: "GK-0"
AssignmentId: "aaa-222" | FormationId: "abc-123" | PlayerId: "user-2" | SlotId: "DF-0"
AssignmentId: "aaa-333" | FormationId: "abc-123" | PlayerId: "user-3" | SlotId: "DF-1"
AssignmentId: "aaa-444" | FormationId: "abc-123" | PlayerId: "user-4" | SlotId: "DF-2"
AssignmentId: "aaa-555" | FormationId: "abc-123" | PlayerId: "user-5" | SlotId: "DF-3"
AssignmentId: "aaa-666" | FormationId: "abc-123" | PlayerId: "user-6" | SlotId: "MF-0"
AssignmentId: "aaa-777" | FormationId: "abc-123" | PlayerId: "user-7" | SlotId: "MF-1"
AssignmentId: "aaa-888" | FormationId: "abc-123" | PlayerId: "user-8" | SlotId: "MF-2"
AssignmentId: "aaa-999" | FormationId: "abc-123" | PlayerId: "user-9" | SlotId: "FW-0"
AssignmentId: "aaa-101" | FormationId: "abc-123" | PlayerId: "user-10" | SlotId: "FW-1"
AssignmentId: "aaa-102" | FormationId: "abc-123" | PlayerId: "user-11" | SlotId: "FW-2"
```

**Constraints:**
- `UNIQUE (FormationId, SlotId)` → Mỗi slot chỉ có 1 player
- `UNIQUE (FormationId, PlayerId)` → Mỗi player chỉ ở 1 slot

---

### 🗃️ Table 3: `match.RoomParticipants` (UPDATE)

Table này **được cập nhật** field `Position` của các players.

**Khi request thành công:**
- System tự động update `Position` của player dựa trên SlotId:
  - `GK-x` → `Position = "Goalkeeper"`
  - `DF-x` → `Position = "Defender"`
  - `MF-x` → `Position = "Midfielder"`
  - `FW-x` → `Position = "Forward"`

**Example:**
Nếu player "user-2" được assign vào slot "DF-0":
```sql
UPDATE match.RoomParticipants
SET Position = 'Defender'
WHERE UserId = 'user-2' AND RoomId = '3fa85f64-...';
```

## 8. SIGNALR REALTIME EVENT

Sau khi set formation thành công, **TẤT CẢ participants** trong room sẽ nhận được event qua SignalR.

### 📡 Event Name: `FormationUpdated`

### 📦 Payload Structure

```json
{
  "roomId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "team": "A",
  "formationName": "4-3-3",
  "assignments": [
    {
      "playerId": "user-id-1",
      "slotId": "GK-0",
      "position": "Goalkeeper"
    },
    {
      "playerId": "user-id-2",
      "slotId": "DF-0",
      "position": "Defender"
    },
    {
      "playerId": "user-id-3",
      "slotId": "DF-1",
      "position": "Defender"
    }
    // ... các assignments khác
  ],
  "updatedAt": "2026-02-09T14:30:00Z"
}
```

### 📝 Payload Fields Explained

| Field | Type | Description |
|-------|------|-------------|
| `roomId` | UUID | ID của room |
| `team` | String | Team A hoặc B vừa được update |
| `formationName` | String | Tên formation mới (VD: "4-3-3") |
| `assignments` | Array | Danh sách player assignments |
| `assignments[].playerId` | UUID | ID của player |
| `assignments[].slotId` | String | Slot của player (VD: "GK-0") |
| `assignments[].position` | String | Vị trí (Goalkeeper/Defender/Midfielder/Forward) |
| `updatedAt` | DateTime | Thời điểm update (UTC) |

## 9. XỬ LÝ EVENT Ở FRONTEND

### JavaScript/TypeScript Example

```javascript
// 1. Kết nối SignalR Hub
const connection = new signalR.HubConnectionBuilder()
    .withUrl("https://api.example.com/hubs/matchroom", {
        accessTokenFactory: () => yourJwtToken
    })
    .build();

// 2. Lắng nghe event FormationUpdated
connection.on("FormationUpdated", (data) => {
    console.log(`Team ${data.team} đã thay đổi formation thành ${data.formationName}`);
    
    // Update UI
    if (data.team === "A") {
        updateTeamAFormation(data.formationName, data.assignments);
    } else {
        updateTeamBFormation(data.formationName, data.assignments);
    }
    
    // Show notification
    showNotification(`Team ${data.team} changed formation to ${data.formationName}`);
    
    // Log chi tiết
    data.assignments.forEach(assignment => {
        console.log(`${assignment.playerId} → ${assignment.position} (${assignment.slotId})`);
    });
});

// 3. Start connection
await connection.start();

// 4. Join room group
await connection.invoke("JoinRoom", roomId);
```

### React Example

```typescript
useEffect(() => {
    const connection = new HubConnectionBuilder()
        .withUrl(`${API_URL}/hubs/matchroom`, {
            accessTokenFactory: () => token
        })
        .withAutomaticReconnect()
        .build();

    connection.on("FormationUpdated", (data: FormationUpdatedEvent) => {
        // Update state
        setFormations(prev => ({
            ...prev,
            [data.team]: {
                name: data.formationName,
                assignments: data.assignments
            }
        }));

        // Show toast
        toast.success(
            `Team ${data.team} đã đổi formation thành ${data.formationName}`
        );
    });

    connection.start()
        .then(() => connection.invoke("JoinRoom", roomId))
        .catch(err => console.error(err));

    return () => {
        connection.stop();
    };
}, [roomId, token]);
```

## 12. TÓM TẮT

### Request Format
```json
{
  "team": "A" | "B",
  "formationName": "4-3-3",
  "assignments": [
    { "playerId": "uuid", "slotId": "GK-0" },
    { "playerId": "uuid", "slotId": "DF-0" },
    ...
  ]
}
```

### Tables Affected
1. **MatchFormations** - INSERT/UPDATE 1 row
2. **FormationAssignments** - DELETE old + INSERT new (N rows)
3. **RoomParticipants** - UPDATE Position field (N rows)

### SignalR Event
- **Event:** `FormationUpdated`
- **Target:** All participants in room
- **Payload:** `{ roomId, team, formationName, assignments[], updatedAt }`

### Authorization
- Must be **Captain** of the team
- Must be in **Open** room
